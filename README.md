# tiny-os
An OS meant to run in TRASH.

The goal of this project is to have a multitasking OS that is lightweight enough to run in embedded microprocessors, yet powerful enough to provide an user with their basic computing needs.

----

## Motivation
A lightbulb is more powerful than an Amiga computer from the 1980s. I want us to be able to build a computer not only from e-waste comuters, but from any computing device. I want this to be able to run in the SoC of a smart bulb, connected to a serial reader, or anything that passes for an output and input device.
